# 实施计划：开源商业化

## 概述

本实施计划将 UIED 导航系统转变为开源和商业双轨产品，**以 AI 功能作为核心差异化卖点**。采用**渐进式开发策略**：先完成开源版发布，同时预留商业化接口，再逐步添加 AI 驱动的 Pro 功能。

**核心 AI 功能**：
- **个人版（¥699）**：AI 智能推荐、AI 搜索助手、AI 内容生成
- **企业版（¥2999）**：AI 数据分析、AI 内容审核（包含所有个人版功能）

**实施时间线**：16 周（约 4 个月）
- 第 1-2 周：开源版核心准备
- 第 2-3 周：商业化基础设施
- 第 4-6 周：AI 核心功能（个人版）⭐ 最高优先级
- 第 7-8 周：辅助 Pro 功能
- 第 9-10 周：企业级 AI 功能 ⭐ 企业核心
- 第 11 周：支付集成
- 第 12-13 周：销售网站
- 第 14-16 周：发布和推广

## 优先级说明

- 🔴 **P0（立即执行）**：开源版核心功能，必须完成才能发布
- 🟡 **P1（并行准备）**：商业化基础设施，可以边开发边准备
- 🟢 **P2（后期完善）**：完整 Pro 功能，开源版发布后再完成

## 数据库说明

- **默认使用 SQLite**：零配置，适合开源版快速安装
- **支持 MySQL/PostgreSQL**：通过环境变量切换，适合企业版
- **本地开发**：直接使用 SQLite，无需 Docker
- **Prisma 配置**：已支持多数据库，只需修改 `DATABASE_URL`
