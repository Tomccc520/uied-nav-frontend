# 主题色和子分类修复说明

## 修复内容

### 1. 主题色配置修复

**问题**: 页面设置的主题色没有生效，主题色应该影响按钮、选中状态等元素。

**解决方案**:
1. 在 `DynamicPage/index.tsx` 中增强了主题色CSS变量的设置：
   - 添加了 `--primary-light`、`--primary-lighter`、`--primary-hover`、`--primary-active` 等变量
   - 使用 `useMemo` 优化性能

2. 在 `common.css` 中添加了主题色覆盖样式：
   - 确保 `.dynamic-page` 容器内的所有使用 `--primary-color` 的元素都能正确继承主题色
   - 包括：侧边栏选中项、搜索按钮、标签hover、卡片hover、标题装饰等

**使用方法**:
1. 在管理后台 → 页面管理 → 编辑页面
2. 设置"主题色"字段（如 `#ff6600`）
3. 保存后刷新前端页面即可看到效果

### 2. 子分类显示问题

**问题**: 后台添加的子分类在前端不显示。

**可能原因**:
1. 网站关联到了父分类而非子分类
2. 子分类没有关联任何网站

**诊断方法**:
打开浏览器控制台，查看以下日志：
```
[SubCategoryTabs] 渲染子分类组件
[SubCategoryTabs] 子分类数量: X
[SubCategoryTabs] 子分类 "XXX" (ID: xxx): Y 个网站
```

**解决方案**:
1. 在管理后台 → 网站管理 → 添加/编辑网站
2. 确保"所属分类"选择的是**子分类**而非父分类
3. 只有关联到子分类的网站才会在子分类标签下显示

### 3. 页面图标配置

**问题**: 页面的头部菜单切换图标设置没有效果。

**解决方案**:
已在 `Navbar.tsx` 中扩展了 `iconMapping`，支持所有 `DesignIcons` 图标。

**可用图标列表**:
- Figma, AI, Design, 3D, Ecommerce, Font, Tool
- Video, Photo, Code, Image, Tutorial, UI
- Inspiration, Material, Color, Audio, Web, Mobile
- Animation, Community, Specs, Data, Blog, Template
- Graphic, Icons, Kit, Prototype, Brand, Plugin
- Developer, Learn, Art, Print, Analytics

**使用方法**:
1. 在管理后台 → 页面管理 → 编辑页面
2. 选择"图标"字段
3. 保存后刷新前端页面
