## 💰 定价策略

### 方案 A：只卖永久版（推荐个人开发者）

**为什么推荐只卖永久版？**

1. **用户更愿意买永久版**
   - 一次付费，永久使用
   - 心理负担小
   - 转化率高

2. **管理简单**
   - 不需要处理续费
   - 不需要到期提醒
   - 减少客服工作

3. **现金流快**
   - 一次性收入
   - 不依赖续费

4. **竞品都是永久版**
   - NiceTheme：永久版
   - 奈斯猫：永久版
   - 大部分 WordPress 主题：永久版

#### 定价表

| 版本 | 价格 | 域名授权 | 更新 |
|------|------|---------|------|
| 开源版 | 免费 | 无限制 | 永久 |
| 个人版 | ¥699 | 1 个 | 1 年 |
| 企业版 | ¥2999 | 3 个 | 终身 |

**说明**：
- 个人版：1 年免费更新，之后 ¥199/年续费更新
- 企业版：终身免费更新 + 源码授权

**个人版**：只卖永久版（¥699）

## 📝 实施步骤

### 1. 代码分支管理

```
main (开源版)
  ├── 所有基础功能
  └── MIT 协议

pro (个人版 + 企业版)
  ├── 基于 main 分支
  ├── 增加高级功能
  ├── 授权验证
  └── 不开源
```

### 2. 功能开关

```javascript
// backend/src/config/features.js

const FEATURES = {
  free: [
    'basic_management',
    'basic_search',
    'basic_seo',
  ],
  personal: [
    ...FEATURES.free,
    'sync',           // 多端同步
    'advanced_search', // 高级搜索
    'no_ads',         // 去广告
  ],
  enterprise: [
    ...FEATURES.personal,
    'statistics',     // 数据统计
    'monitoring',     // 网站监控
    'advanced_seo',   // 高级 SEO
  ]
};

// 检查功能权限
function hasFeature(license, feature) {
  const features = FEATURES[license.type] || FEATURES.free;
  return features.includes(feature);
}
```

### 3. 授权验证

```javascript
// 验证授权
async function verifyLicense(licenseKey, domain) {
  const license = await db.license.findOne({ key: licenseKey });
  
  if (!license) {
    return { valid: false, message: '授权码无效' };
  }
  
  // 检查域名
  if (license.domain && license.domain !== domain) {
    return { valid: false, message: '域名不匹配' };
  }
  
  // 检查是否过期（只对年付版）
  if (license.expiresAt && license.expiresAt < new Date()) {
    return { valid: false, message: '授权已过期' };
  }
  
  // 检查更新权限
  const canUpdate = !license.updateUntil || license.updateUntil > new Date();
  
  return {
    valid: true,
    type: license.type,
    features: FEATURES[license.type],
    canUpdate
  };
}
```
