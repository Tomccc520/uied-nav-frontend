### 🔧 配置说明

#### 数据源切换

在 `frontend/.env` 中设置：

```bash
# 使用API数据
REACT_APP_DATA_SOURCE=api

# 使用静态数据
REACT_APP_DATA_SOURCE=static

# 自动模式（默认，优先API）
REACT_APP_DATA_SOURCE=auto
```

### 🧪 测试API

```bash
# 获取页面完整数据
curl http://localhost:3001/api/pages/uiux/full
curl http://localhost:3001/api/pages/ai/full
curl http://localhost:3001/api/pages/3d/full

# 获取热门推荐
curl http://localhost:3001/api/hot-recommendations/active?pageSlug=home

# AI智能搜索
curl -X POST http://localhost:3001/api/ai-config/smart-search \
  -H "Content-Type: application/json" \
  -d '{"query": "设计工具", "limit": 10}'

# WordPress组件配置
curl http://localhost:3001/api/wordpress/widgets/active?pageSlug=home
```
