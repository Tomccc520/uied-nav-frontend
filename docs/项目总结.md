## 🎯 核心特性

### 前后端分离
```
用户前端 (3000) ──▶ API后端 (3001) ◀── 管理后台 (5173)
```

### 动态内容管理
- 所有内容通过管理后台修改
- 实时生效，无需重新部署
- 非技术人员也能轻松管理

### 安全认证
- Token-based 认证
- 路由守卫保护
- 密码加密存储

## 🚀 部署建议

### 开发环境（当前）
- 前端: `npm start` (3000)
- 后端: `npm run dev` (3001)
- 管理后台: `npm run dev` (5173)

### 生产环境

**前端：**
```bash
cd frontend
npm run build
# 部署 build/ 到 Nginx 或 CDN
```

**后端：**
```bash
cd backend
npm start
# 使用 PM2 管理进程
pm2 start src/index.js --name uied-api
```

**管理后台：**
```bash
cd admin
npm run build
# 部署 dist/ 到服务器
```
