## 🐛 常见问题

### Q: 前端没有显示新添加的菜单？
**A:** 刷新页面（Ctrl+R 或 Cmd+R）

### Q: 管理后台无法登录？
**A:** 
1. 检查后端是否运行
2. 检查管理员账号是否创建：`cd backend && npm run seed:admin`

### Q: 前端显示 "加载中..." 不消失？
**A:**
1. 打开开发者工具查看 Network 请求
2. 检查 API 请求是否成功
3. 检查 `.env` 文件中的 API 地址

### Q: 修改后没有生效？
**A:**
1. 清除浏览器缓存
2. 硬刷新（Ctrl+Shift+R 或 Cmd+Shift+R）
3. 检查数据库中的 `visible` 字段是否为 `true`
