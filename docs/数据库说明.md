# 数据库说明文档

## 📊 数据库方案

### 选择 SQLite 的原因

本项目使用 **SQLite** 作为数据库，原因如下：

| 特点 | 说明 |
|------|------|
| **零配置** | 无需安装数据库服务器，开箱即用 |
| **轻量级** | 单个文件存储，易于备份和迁移 |
| **性能优秀** | 对于中小型项目完全够用 |
| **跨平台** | 支持 Windows、Mac、Linux |
| **易于部署** | 直接复制 `.db` 文件即可 |

### 数据库文件位置

```
backend/prisma/dev.db          # 数据库文件
backend/prisma/dev.db-journal  # 临时日志文件
```

## 🔧 数据库操作

### 查看数据库

使用 Prisma Studio 可视化管理：

```bash
cd backend
npm run prisma:studio
```

访问 http://localhost:5555 即可查看和编辑数据

### 备份数据库

直接复制数据库文件：

```bash
# 备份
cp backend/prisma/dev.db backend/prisma/dev.db.backup

# 恢复
cp backend/prisma/dev.db.backup backend/prisma/dev.db
```

### 重置数据库

```bash
cd backend

# 删除数据库
rm prisma/dev.db

# 重新创建
npm run prisma:migrate

# 填充测试数据
npm run seed:all
```

### 修改数据库结构

1. 编辑 `backend/prisma/schema.prisma`
2. 运行迁移命令：

```bash
npm run prisma:migrate
```

## 📈 数据库升级方案

### 小型项目（当前）
- **SQLite** - 适合 < 10万条数据
- 单文件存储，易于管理

### 中型项目
- **MySQL** - 适合 10万-1000万条数据
- 需要修改 `schema.prisma` 中的 datasource

```prisma
datasource db {
  provider = "mysql"
  url      = env("DATABASE_URL")
}
```

### 大型项目
- **PostgreSQL** - 适合 > 1000万条数据
- 更强大的查询性能和扩展性

```prisma
datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}
```

## 🔐 数据安全

### 密码加密

使用 SHA256 加密存储（生产环境建议用 bcrypt）

```javascript
import crypto from 'crypto';

const hashPassword = (password) => {
  return crypto.createHash('sha256').update(password).digest('hex');
};
```

### 数据备份建议

1. **定期备份** - 每天自动备份数据库文件
2. **异地存储** - 备份到云存储（OSS、S3等）
3. **版本控制** - 保留最近7天的备份

### 敏感数据

- 密码已加密存储
- Token 存储在内存中（重启后失效）
- 生产环境建议使用 JWT + Redis

## ❓ 常见问题

### Q: 数据库文件在哪里？
A: `backend/prisma/dev.db`

### Q: 如何导出数据？
A: 使用 Prisma Studio 或直接复制 `.db` 文件

### Q: 如何迁移到 MySQL？
A: 
1. 修改 `schema.prisma` 的 provider
2. 配置 MySQL 连接字符串
3. 运行 `npm run prisma:migrate`

### Q: 数据库损坏怎么办？
A: 从备份文件恢复，或重新运行 `seed:all`
