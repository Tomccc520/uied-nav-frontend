# SEO 抓取功能 - 部署步骤（简化版）

### 方式一：只更新管理后台（推荐，最简单）

如果你只想让管理员使用 SEO 抓取功能，只需要：

```
1. 上传管理后台文件

2. 上传后端文件（3个文件）
   本地：backend/src/services/seoScraperService.js
   服务器：/www/wwwroot/hao.uied.cn/backend/src/services/seoScraperService.js
```

## 🔧 部署步骤

### 第一步：在服务器安装 cheerio

通过宝塔面板或 SSH 连接到服务器，执行：

```bash
# 进入后端目录
cd /www/wwwroot/hao.uied.cn/backend

# 安装 cheerio
npm install cheerio

# 查看是否安装成功
npm list cheerio
```

**预期输出**：
```
backend@1.0.0 /www/wwwroot/hao.uied.cn/backend
└── cheerio@1.0.0
```

### 第二步：上传文件

#### 使用宝塔面板上传（推荐）

1. **上传管理后台**：
   - 打开宝塔文件管理器
   - 进入 `/www/wwwroot/hao.uied.cn/admin/`
   - 删除旧的 `dist` 文件夹
   - 上传本地的 `admin/dist/` 文件夹

2. **上传后端文件**：
   - 进入 `/www/wwwroot/hao.uied.cn/backend/src/services/`
   - 上传 `seoScraperService.js`
   
   - 进入 `/www/wwwroot/hao.uied.cn/backend/src/routes/`
   - 上传 `seoScraperRoutes.js`
   
   - 进入 `/www/wwwroot/hao.uied.cn/backend/src/`
   - 上传 `index.js`（覆盖原文件）

3. **上传前端文件**（可选）：
   - 进入 `/www/wwwroot/hao.uied.cn/frontend/`
   - 删除旧的 `build` 文件夹
   - 上传本地的 `frontend/build/` 文件夹

#### 使用 FTP/SFTP 上传

使用 FileZilla 或其他 FTP 工具，按照上面的路径上传对应文件。

### 第三步：重启后端服务

#### 使用 Docker（如果你用 Docker）

```bash
docker restart uied-api
```

#### 使用 PM2（如果你用 PM2）

```bash
pm2 restart backend
# 或
pm2 restart all
```

#### 使用宝塔面板

1. 打开宝塔面板
2. 进入"软件商店" > "已安装"
3. 找到 "PM2 管理器" 或 "Node.js 版本管理"
4. 重启你的 Node.js 应用

#### 直接重启（如果直接运行）

```bash
# 停止旧进程
pkill -f "node.*backend"

# 启动新进程
cd /www/wwwroot/hao.uied.cn/backend
nohup npm run dev > backend.log 2>&1 &
```

### 第四步：验证部署

1. **检查后端是否正常运行**：
   ```bash
   curl http://localhost:3001/api/health
   ```
   
   预期输出：
   ```json
   {"status":"ok","message":"UIED API is running"}
   ```

2. **测试 SEO 抓取功能**：
   - 打开管理后台：https://hao.uied.cn/admin
   - 登录账号
   - 进入"网站管理"
   - 点击"添加网站"
   - 输入测试 URL：`https://dribbble.com`
   - 点击"SEO"按钮
   - 查看是否自动填充了标题、描述、标签

3. **测试图标 URL 功能**：
   - 在添加网站界面
   - 找到"或输入图标URL"输入框
   - 输入：`https://cdn.dribbble.com/assets/favicon-63b2904a073c89b52b19aa08cebc16a154bcf83fee8ecc6439968b1e6db569c7.ico`
   - 按回车或点击"确定"
   - 查看图标是否显示

## 🚨 常见问题

### 问题1：上传后功能不生效

**原因**：后端服务没有重启

**解决**：
```bash
# 查看后端进程
ps aux | grep node

# 重启服务
docker restart uied-api
# 或
pm2 restart backend
```

### 问题2：点击 SEO 按钮没反应

**原因**：cheerio 没有安装

**解决**：
```bash
cd /www/wwwroot/hao.uied.cn/backend
npm install cheerio
docker restart uied-api  # 或 pm2 restart backend
```

### 问题3：SEO 抓取返回空数据

**原因**：目标网站没有 SEO meta 标签

**解决**：
- 这是正常的，不是所有网站都有完整的 SEO 信息
- 系统会返回基于域名的默认信息
- 可以手动填写标题和描述

### 问题4：管理后台显示旧版本

**原因**：浏览器缓存

**解决**：
- 按 Ctrl+Shift+R（Windows）或 Cmd+Shift+R（Mac）强制刷新
- 或清除浏览器缓存

## 📝 重要提示

### 关于 .env 和 dev.db

**不要上传这两个文件！**

- `.env` - 包含密钥和配置，保持服务器上的不变
- `dev.db` - 数据库文件，保持服务器上的不变

只上传代码文件，不要覆盖配置和数据！

### 关于 node_modules

**不要上传 node_modules 文件夹！**

- 这个文件夹非常大（几百MB）
- 服务器上已经有了
- 只需要运行 `npm install cheerio` 安装新依赖
