# 🚀 快速启动指南 - 新功能

## 📋 前置条件

确保已完成数据库迁移：
```bash
cd backend
npx prisma migrate dev
npx prisma generate
node src/utils/seedSocialMedia.js
```

## 🎯 快速体验三大新功能

### 1️⃣ 图片上传功能（2分钟）

1. 打开管理后台：http://localhost:3002
2. 登录（admin / admin123）
3. 点击左侧菜单：**站点设置 > 基本设置**
4. 在"资源设置"区域：
   - 点击 **"上传 Logo"** 按钮
   - 选择一张图片（PNG/SVG 推荐）
   - 看到预览后点击 **"保存设置"**
5. 打开前端：http://localhost:3000
6. 刷新页面，查看顶部导航栏的 Logo 是否更新 ✨

### 2️⃣ 关注交流管理（3分钟）

1. 在管理后台点击：**站点设置 > 关注交流**
2. 查看默认的两个配置（交流群、公众号）
3. 点击 **"添加社交媒体"**：
   - 名称：微博
   - 类型：微博
   - 上传二维码图片
   - 描述：关注我们的微博
   - 排序：3
   - 确保"显示"开关打开
4. 点击 **"确定"**
5. 打开前端：http://localhost:3000
6. 滚动到页面底部，查看"关注交流"区域
7. 确认新添加的微博二维码显示 ✨

### 3️⃣ 数据自动刷新（1分钟）

1. 打开前端：http://localhost:3000
2. 在管理后台修改站点名称
3. 等待30秒（或手动刷新前端）
4. 查看前端是否自动更新 ✨

## 🔧 API 测试

### 测试图片上传
```bash
curl -X POST http://localhost:3001/api/upload/image \
  -F "file=@/path/to/image.png"
```

### 测试社交媒体 API
```bash
# 获取列表
curl http://localhost:3001/api/social-media

# 创建新项
curl -X POST http://localhost:3001/api/social-media \
  -H "Content-Type: application/json" \
  -d '{
    "name": "测试",
    "type": "other",
    "qrCodeUrl": "http://example.com/qr.jpg",
    "description": "测试",
    "order": 10,
    "visible": true
  }'
```

## ⚠️ 注意事项

1. **图片大小**：限制 5MB
2. **图片格式**：jpg, png, svg, ico, webp, gif
3. **上传目录**：确保 `backend/uploads/` 有写入权限
4. **数据刷新**：修改后等待30秒或手动刷新页面
