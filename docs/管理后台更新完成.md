## 🔍 如果看不到菜单

### 方法1：强制刷新浏览器
```
Windows/Linux: Ctrl + Shift + R
Mac: Cmd + Shift + R
```

### 方法2：清除浏览器缓存
1. 打开开发者工具 (F12)
2. 右键点击刷新按钮
3. 选择"清空缓存并硬性重新加载"

### 方法3：重启管理后台服务
```bash
# 停止当前进程 (Ctrl + C)
# 然后重新启动
cd admin
npm run dev
```

## 📝 功能说明

### 页面管理
- **基本信息**：名称、URL路径、类型、图标、描述
- **搜索配置**：搜索框占位符、启用/禁用搜索
- **显示配置**：热门推荐、分类显示
- **分类管理**：为每个页面配置显示的分类

### 社交媒体管理
- **基本信息**：名称、类型（微信群、公众号等）
- **二维码**：上传二维码图片
- **链接**：可选的网页链接
- **描述**：显示在二维码下方的文字
- **排序**：控制显示顺序
- **显示**：控制是否在前端显示
