# 分类对接指南

## 📋 概述

前端左侧分类菜单需要从后端 API 获取数据，实现动态管理。

---

## 🔗 API 接口

### 获取所有分类

**接口：** `GET /api/categories`

**响应示例：**
```json
[
  {
    "id": "cmji7x7fv0000ifb1...",
    "name": "AI工具",
    "slug": "ai-tools",
    "icon": "ai",
    "color": "#667EEA",
    "order": 1,
    "_count": {
      "websites": 4
    }
  }
]
```

---

## 🎯 对接步骤

### 1. 使用现有 Hook

前端已经创建好了 `useCategories` Hook：

```tsx
import { useCategories } from './hooks/useCategories';

function MyComponent() {
  const { categories, loading, error } = useCategories();

  if (loading) return <div>加载中...</div>;
  if (error) return <div>加载失败</div>;

  return (
    <div>
      {categories.map(cat => (
        <div key={cat.id}>{cat.name}</div>
      ))}
    </div>
  );
}
```

### 2. 转换数据格式

将 API 数据转换为 CategorySidebar 需要的格式：

```tsx
const navItems = categories.map(cat => ({
  id: cat.slug,
  name: cat.name,
  count: cat._count?.websites || 0,
  icon: cat.icon,
  color: cat.color,
}));
```

### 3. 使用 CategorySidebar

```tsx
<CategorySidebar
  config={{
    title: '分类导航',
    type: NavMenuType.DESIGN,
  }}
  navItems={navItems}
  activeItem={activeCategory}
  onItemClick={handleCategoryClick}
/>
```

---

## 📝 完整示例

```tsx
import React, { useState } from 'react';
import { useCategories } from '../../hooks/useCategories';
import CategorySidebar from '../../components/CategorySidebar';
import { NavMenuType } from '../../types';

export default function MyPage() {
  const { categories, loading } = useCategories();
  const [activeCategory, setActiveCategory] = useState('');

  // 转换数据格式
  const navItems = categories.map(cat => ({
    id: cat.slug,
    name: cat.name,
    count: cat._count?.websites || 0,
    icon: cat.icon,
    color: cat.color,
  }));

  const handleCategoryClick = (categoryId: string) => {
    setActiveCategory(categoryId);
    // 加载该分类的网站数据
  };

  if (loading) {
    return <div>加载中...</div>;
  }

  return (
    <div className="page-container">
      <CategorySidebar
        config={{
          title: '分类导航',
          type: NavMenuType.DESIGN,
        }}
        navItems={navItems}
        activeItem={activeCategory}
        onItemClick={handleCategoryClick}
      />
      
      <main>
        {/* 网站列表 */}
      </main>
    </div>
  );
}
```

## 🔄 数据流程

```
1. 用户访问页面
   ↓
2. useCategories Hook 调用 API
   ↓
3. 获取分类数据
   ↓
4. 转换为 navItems 格式
   ↓
5. 传递给 CategorySidebar
   ↓
6. 渲染分类菜单
```

## 🎨 管理后台操作

### 添加新分类

1. 登录管理后台 http://localhost:5173
2. 进入 "分类管理"
3. 点击 "添加分类"
4. 填写信息：
   - 名称：`新分类`
   - Slug：`new-category`
   - 图标：`tool`
   - 颜色：`#1890ff`
   - 排序：`99`
5. 保存

### 查看前端效果

1. 刷新前端页面
2. 左侧菜单应该显示新分类
3. 点击分类查看对应网站

## 🐛 常见问题

### Q: 分类不显示？
**A:** 
1. 检查后端是否运行
2. 检查 API 请求是否成功（F12 → Network）
3. 检查数据库中是否有分类数据

### Q: 图标不显示？
**A:** 
1. 检查 icon 字段是否正确
2. 参考 `CategorySidebar/index.tsx` 中的 `defaultIconMap`
3. 确保图标名称匹配

### Q: 颜色不生效？
**A:** 
1. 检查 color 字段格式（如 `#1890ff`）
2. 检查 CSS 变量是否正确应用
