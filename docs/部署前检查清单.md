## ⚠️ 部署前必须完成

### 1. 修改环境变量（最重要！）

编辑 `backend/.env`：

```bash
# 生成 JWT 密钥（在终端运行）
openssl rand -hex 64

# 生成密码盐值
openssl rand -hex 32
```

```env
NODE_ENV=production
JWT_SECRET="粘贴上面生成的64位密钥"
PASSWORD_SALT="粘贴上面生成的32位盐值"
CORS_ORIGINS="https://你的域名.com,https://admin.你的域名.com"
```

### 2. 修改管理员密码

部署后第一时间登录后台修改默认密码！

### 3. 数据库备份

```bash
# 备份 SQLite 数据库
cp backend/prisma/dev.db backend/prisma/prod.db

# 修改 .env 中的数据库路径
DATABASE_URL="file:./prod.db"
```
