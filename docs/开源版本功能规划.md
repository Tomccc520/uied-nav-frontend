## 📋 项目概述

UIED-NAV 是一个现代化的设计资源导航网站系统，采用前后端分离架构，支持一键部署和可视化管理。

### 技术栈

| 模块 | 技术 |
|------|------|
| 前端 | React 19 + TypeScript + CRA |
| 后台 | React 19 + TypeScript + Vite + Ant Design 6 |
| 后端 | Node.js + Express + Prisma ORM |
| 数据库 | SQLite（默认）/ MySQL（可选） |

## 💡 为什么选择这种模式？

### 1. WordPress 的成功经验

WordPress 采用开源 + 商业的模式：
- **开源核心**：免费使用，全球 43% 的网站使用
- **商业生态**：主题市场、插件市场、托管服务
- **年收入**：WordPress.com 年收入超过 5 亿美元

### 2. 双赢策略

**对用户**：
- 免费版满足基本需求
- 付费版提供更多价值
- 自由选择，无强制消费

**对开发者**：
- 开源获得用户和口碑
- 商业版实现盈利
- 可持续发展和迭代

### 3. 市场需求

- 导航网站市场需求大
- 现有解决方案不够完善
- 用户愿意为优质产品付费

## 🔐 安全考虑

### 开源版安全措施

1. **安装锁定**：安装完成后禁用安装入口
2. **密码加密**：bcrypt 加密存储
3. **JWT 认证**：Token 过期机制
4. **CORS 配置**：限制跨域请求
5. **SQL 注入防护**：Prisma ORM 参数化查询
6. **XSS 防护**：输入过滤和输出转义

### 敏感信息处理

开源前需要移除：
- [ ] 真实数据库数据
- [ ] API 密钥
- [ ] 第三方服务配置
- [ ] 个人信息
