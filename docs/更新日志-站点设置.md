# 更新日志 - 站点设置功能

## 📅 更新时间
2025年12月23日

## 🎯 更新内容

### 1. ✅ 站点设置支持图片上传
- 管理后台的"站点设置"页面现在支持上传Logo和Favicon
- 支持拖拽上传和点击上传
- 上传成功后自动显示预览
- 支持的格式：Logo（SVG/PNG/JPG），Favicon（ICO/PNG）

### 2. ✅ 站点设置保存后前端自动更新
- 优化了前端的站点信息Hook（useSiteInfo）
- 添加了favicon自动更新功能
- Navbar组件现在会根据站点信息动态更新Logo
- 保存后刷新前端页面即可看到更新

### 3. ✅ 左侧菜单对接后台设置
- 顶部导航栏已完全对接后台API
- 支持从管理后台配置菜单项
- 支持二级下拉菜单
- 支持外部链接和内部路由
- 支持菜单排序和可见性控制

## 🚀 如何使用

### 管理员操作
1. 登录管理后台（http://localhost:5173）
2. 进入"站点设置"页面
3. 上传Logo和Favicon，填写站点信息
4. 点击"保存设置"
5. 打开前端网站（http://localhost:3000）并刷新

### 配置导航菜单
1. 在管理后台进入"导航菜单"页面
2. 添加/编辑菜单项
3. 设置菜单顺序和可见性
4. 刷新前端页面查看效果

## 🔧 技术细节

### API接口
- `GET /api/site-info` - 获取站点信息
- `PUT /api/site-info` - 更新站点信息
- `POST /api/upload/single` - 上传图片
- `GET /api/settings/nav-menus` - 获取导航菜单

### 数据库表
- `SiteInfo` - 站点信息
- `NavMenu` - 导航菜单
- `FooterGroup` - 页脚分组
- `FooterLink` - 页脚链接
- `FriendLink` - 友情链接

## ⚠️ 注意事项

1. **图片上传**
   - Logo推荐尺寸：200x50px
   - Favicon推荐尺寸：32x32px
   - 建议图片大小不超过2MB

2. **前端更新**
   - 修改站点设置后需要刷新前端页面
   - 如果更新没有生效，尝试硬刷新（Ctrl+Shift+R）

3. **导航菜单**
   - 只有设置为"可见"的菜单才会显示
   - 菜单按"顺序"字段排序
   - 外部链接会在新标签页打开
