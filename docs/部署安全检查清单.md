# 🔒 后台安全检查清单

## ✅ 已实现的安全措施

### 1. 登录安全
- [x] **登录失败锁定** - 5次失败后锁定IP 30分钟
- [x] **速率限制** - 登录接口 15次/15分钟
- [x] **PBKDF2 密码加密** - 10000次迭代，比 SHA256 更安全
- [x] **防止用户名枚举** - 用户不存在也返回相同错误信息
- [x] **登录日志记录** - 记录所有登录尝试（成功/失败/IP）

### 2. API 安全
- [x] **JWT 认证** - 所有管理接口需要 token
- [x] **Helmet 安全头** - XSS、点击劫持等防护
- [x] **全局速率限制** - 1000次/15分钟
- [x] **CORS 配置** - 可配置允许的域名

### 3. 文件上传安全
- [x] **文件类型限制** - 只允许图片格式
- [x] **文件大小限制** - 最大 5MB
- [x] **路径遍历防护** - 删除文件时验证路径
- [x] **随机文件名** - 防止文件名猜测

### 4. 输入验证
- [x] **express-validator** - 关键接口有输入验证
- [x] **Prisma ORM** - 自动防止 SQL 注入

### 5. 错误处理
- [x] **统一错误处理** - 不泄露敏感堆栈信息
- [x] **生产环境隐藏详情** - 只在开发环境显示详细错误

## ⚠️ 建议增加的安全措施

### 1. 管理后台路径混淆（推荐）

当前管理后台路径是 `/admin`，容易被扫描器发现。

**建议**：在 Nginx 配置中使用自定义路径：

```nginx
# 将 /your-secret-admin-path 代理到管理后台
location /your-secret-admin-path {
    alias /www/wwwroot/your-site/admin/dist;
    try_files $uri $uri/ /your-secret-admin-path/index.html;
}
```

### 2. 添加 IP 白名单（可选）

如果只有你自己使用后台，可以在 Nginx 层面限制 IP：

```nginx
location /api/auth/login {
    # 只允许特定 IP 访问登录接口
    allow 你的IP地址;
    deny all;
    
    proxy_pass http://127.0.0.1:3001;
}
```

### 3. 添加登录通知（可选）

在 `authRoutes.js` 登录成功后发送通知：

```javascript
// 登录成功后可以发送邮件/微信通知
// 这样即使有人破解了密码，你也能第一时间知道
```

### 4. 定期清理登录日志

添加定时任务清理超过 30 天的日志：

```bash
# 在宝塔计划任务中添加
0 3 * * * curl -X DELETE "http://localhost:3001/api/logs/cleanup?days=30" -H "Authorization: Bearer YOUR_TOKEN"
```

## 🚀 部署时必须做的事

### 1. 修改环境变量

```bash
# 生成安全的 JWT 密钥
openssl rand -hex 64

# 生成密码盐值
openssl rand -hex 32
```

编辑 `backend/.env`：
```env
NODE_ENV=production
JWT_SECRET="生成的64位密钥"
PASSWORD_SALT="生成的32位盐值"
CORS_ORIGINS="https://你的域名.com"
```

### 2. 修改默认密码

部署后立即登录后台修改密码！

### 3. 配置 HTTPS

确保所有流量都通过 HTTPS，在宝塔中申请免费 SSL 证书。

### 4. 数据库文件权限

```bash
# 确保数据库文件只有应用可以访问
chmod 600 backend/prisma/dev.db
```
