# 登录系统说明

## 🔐 认证流程

```
┌─────────────┐      ┌─────────────┐      ┌─────────────┐
│  登录页面    │─────▶│  后端验证    │─────▶│  返回Token  │
│  (Login)    │      │  (authAPI)  │      │             │
└─────────────┘      └─────────────┘      └─────────────┘
       │                                          │
       │                                          ▼
       │                                   ┌─────────────┐
       │                                   │ 保存到本地   │
       │                                   │ localStorage│
       │                                   └─────────────┘
       │                                          │
       └──────────────────────────────────────────┘
                      跳转到管理后台

每次请求都会携带 Token ──▶ 后端验证 ──▶ 返回数据
```

## 🔑 Token 机制

### Token 生成

登录成功后，后端生成一个随机 Token：

```javascript
const token = crypto.randomBytes(32).toString('hex');
// 示例: "a1b2c3d4e5f6..."
```

### Token 存储

**前端（localStorage）：**
```javascript
localStorage.setItem('token', token);
localStorage.setItem('user', JSON.stringify(user));
```

**后端（内存 Map）：**
```javascript
tokens.set(token, {
  adminId: admin.id,
  username: admin.username,
  createdAt: Date.now(),
});
```

### Token 有效期

- **24小时** 自动过期
- 重启后端服务会清空所有 Token
- 退出登录会删除 Token

## 🛡️ 路由守卫

### 前端路由守卫

```tsx
function PrivateRoute({ children }) {
  const token = localStorage.getItem('token');
  if (!token) {
    return <Navigate to="/login" replace />;
  }
  return <>{children}</>;
}
```

**作用：** 未登录用户访问管理页面会自动跳转到登录页

### API 请求拦截

```typescript
// 请求拦截器 - 自动添加 Token
api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// 响应拦截器 - 处理 401 错误
api.interceptors.response.use(
  (response) => response,
  (error) => {
    if (error.response?.status === 401) {
      // Token 过期，跳转登录
      localStorage.removeItem('token');
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);
```

## 📡 API 接口

### 1. 登录

**接口：** `POST /api/auth/login`

**请求：**
```json
{
  "username": "admin",
  "password": "admin123"
}
```

**响应：**
```json
{
  "token": "a1b2c3d4e5f6...",
  "user": {
    "id": "cmji7x8e50001...",
    "username": "admin",
    "email": "admin@uied.cn"
  }
}
```

---

### 2. 验证 Token

**接口：** `GET /api/auth/verify`

**请求头：**
```
Authorization: Bearer a1b2c3d4e5f6...
```

**响应：**
```json
{
  "user": {
    "id": "cmji7x8e50001...",
    "username": "admin"
  }
}
```

---

### 3. 退出登录

**接口：** `POST /api/auth/logout`

**请求头：**
```
Authorization: Bearer a1b2c3d4e5f6...
```

**响应：**
```json
{
  "message": "已退出登录"
}
```

---

### 4. 修改密码

**接口：** `PUT /api/auth/password`

**请求头：**
```
Authorization: Bearer a1b2c3d4e5f6...
```

**请求：**
```json
{
  "oldPassword": "admin123",
  "newPassword": "newpassword123"
}
```

**响应：**
```json
{
  "message": "密码修改成功"
}
```

## 🔒 安全措施

### 当前实现（开发环境）

| 措施 | 说明 |
|------|------|
| 密码加密 | SHA256 哈希 |
| Token 存储 | 内存 Map |
| Token 过期 | 24小时 |
| HTTPS | 未启用 |

### 生产环境建议

| 措施 | 推荐方案 |
|------|----------|
| 密码加密 | **bcrypt** (更安全) |
| Token 存储 | **Redis** (支持分布式) |
| Token 类型 | **JWT** (无状态) |
| HTTPS | **必须启用** |
| 限流 | **防止暴力破解** |
| 日志 | **记录登录行为** |

## 🐛 常见问题

### Q: 登录后刷新页面又要重新登录？
A: 检查 localStorage 是否正常保存 Token

### Q: Token 过期时间能修改吗？
A: 可以，修改 `backend/src/routes/authRoutes.js` 中的过期时间

```javascript
// 24小时 = 24 * 60 * 60 * 1000
if (Date.now() - tokenData.createdAt > 24 * 60 * 60 * 1000) {
  // 修改这里的数字
}
```

### Q: 如何添加新管理员？
A: 目前只支持单个管理员，可以通过 Prisma Studio 手动添加

### Q: 忘记密码怎么办？
A: 
1. 删除数据库中的管理员记录
2. 重新运行 `npm run seed:admin`
3. 使用默认密码登录
