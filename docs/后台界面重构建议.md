> 更新时间：2026-01-17  
> 作者：Tomda

---

## 🎯 当前问题分析

### 问题 1：菜单结构不清晰
- 功能太多，找不到想要的
- 分类不合理
- 层级混乱

### 问题 2：页面布局不统一
- 有的页面用 Table，有的用 Card
- 操作按钮位置不一致
- 表单样式不统一

### 问题 3：用户体验不够好
- 操作步骤太多
- 反馈不及时
- 没有快捷操作

### 方案 3：优化操作流程 ⭐⭐⭐⭐

**快速操作**：
```tsx
// 仪表板快速操作
<QuickActions>
  <Action icon={<PlusOutlined />} title="添加网站" onClick={...} />
  <Action icon={<FolderOutlined />} title="添加分类" onClick={...} />
  <Action icon={<FileOutlined />} title="添加页面" onClick={...} />
  <Action icon={<UploadOutlined />} title="批量导入" onClick={...} />
</QuickActions>
```

**批量操作**：
```tsx
// 列表页批量操作
<BatchActions selectedCount={selectedRows.length}>
  <Button>批量删除</Button>
  <Button>批量启用</Button>
  <Button>批量禁用</Button>
  <Button>批量导出</Button>
</BatchActions>
```

**内联编辑**：
```tsx
// 表格内直接编辑
<Table
  columns={[
    {
      title: '网站名称',
      dataIndex: 'name',
      editable: true,  // 支持内联编辑
    }
  ]}
/>
```

## 📝 代码示例

### 示例 1：标准列表页组件

```tsx
/**
 * @file components/PageLayout/ListPage.tsx
 * @description 标准列表页模板
 */

import React from 'react';
import { Card, Button, Input, Table, Space } from 'antd';
import { PlusOutlined, SearchOutlined } from '@ant-design/icons';

interface ListPageProps {
  title: string;
  onAdd?: () => void;
  onSearch?: (value: string) => void;
  columns: any[];
  dataSource: any[];
  loading?: boolean;
  pagination?: any;
}

export const ListPage: React.FC<ListPageProps> = ({
  title,
  onAdd,
  onSearch,
  columns,
  dataSource,
  loading,
  pagination,
}) => {
  return (
    <div className="list-page">
      {/* 页面头部 */}
      <div className="page-header">
        <h1>{title}</h1>
        {onAdd && (
          <Button type="primary" icon={<PlusOutlined />} onClick={onAdd}>
            新增
          </Button>
        )}
      </div>

      {/* 搜索和筛选 */}
      <Card bordered={false} style={{ marginBottom: 16 }}>
        <Space>
          <Input.Search
            placeholder="搜索..."
            onSearch={onSearch}
            style={{ width: 300 }}
            prefix={<SearchOutlined />}
          />
          {/* 其他筛选器 */}
        </Space>
      </Card>

      {/* 数据表格 */}
      <Card bordered={false}>
        <Table
          columns={columns}
          dataSource={dataSource}
          loading={loading}
          pagination={pagination}
          rowKey="id"
        />
      </Card>
    </div>
  );
};
```

### 示例 2：使用列表页模板

```tsx
/**
 * @file pages/Websites.tsx
 * @description 网站管理页面
 */

import React from 'react';
import { ListPage } from '@/components/PageLayout/ListPage';
import { Button, Space, Tag } from 'antd';
import { EditOutlined, DeleteOutlined } from '@ant-design/icons';

export const Websites: React.FC = () => {
  const columns = [
    {
      title: '网站名称',
      dataIndex: 'name',
      key: 'name',
    },
    {
      title: 'URL',
      dataIndex: 'url',
      key: 'url',
    },
    {
      title: '分类',
      dataIndex: 'category',
      key: 'category',
      render: (category: any) => <Tag>{category.name}</Tag>,
    },
    {
      title: '状态',
      dataIndex: 'status',
      key: 'status',
      render: (status: string) => (
        <Tag color={status === 'active' ? 'green' : 'red'}>
          {status === 'active' ? '启用' : '禁用'}
        </Tag>
      ),
    },
    {
      title: '操作',
      key: 'action',
      render: (_, record) => (
        <Space>
          <Button
            type="link"
            icon={<EditOutlined />}
            onClick={() => handleEdit(record)}
          >
            编辑
          </Button>
          <Button
            type="link"
            danger
            icon={<DeleteOutlined />}
            onClick={() => handleDelete(record)}
          >
            删除
          </Button>
        </Space>
      ),
    },
  ];

  return (
    <ListPage
      title="网站管理"
      onAdd={handleAdd}
      onSearch={handleSearch}
      columns={columns}
      dataSource={websites}
      loading={loading}
      pagination={pagination}
    />
  );
};
```

## 💡 关键建议

1. **不要一次性重构所有页面**
   - 先重构核心页面（网站、分类）
   - 再逐步重构其他页面
   - 保持系统可用

2. **保持 Ant Design 风格**
   - 不要过度自定义
   - 使用 Ant Design 组件
   - 遵循 Ant Design 设计规范

3. **注重用户体验**
   - 减少操作步骤
   - 提供快捷操作
   - 及时反馈

4. **保持简洁**
   - 不要堆砌功能
   - 隐藏不常用功能
   - 突出核心功能

---

**记住**：好的后台界面应该让用户 3 秒内找到想要的功能！
