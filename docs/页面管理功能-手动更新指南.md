## 📚 API 接口

### 页面管理
```
GET    /api/pages           - 获取所有页面
GET    /api/pages/:slug     - 获取单个页面
POST   /api/pages           - 创建页面
PUT    /api/pages/:id       - 更新页面
DELETE /api/pages/:id       - 删除页面
```

### 页面分类管理
```
POST   /api/pages/:pageId/categories                - 添加分类
PUT    /api/pages/:pageId/categories/:categoryId    - 更新分类
DELETE /api/pages/:pageId/categories/:categoryId    - 删除分类
```

## ⚠️ 注意事项

1. **URL路径唯一性** - slug 必须唯一
2. **类型标识** - type 用于前端识别，建议与 slug 相同
3. **图标名称** - 必须是前端已定义的图标名称
4. **分类关联** - 删除页面会自动删除关联的分类
