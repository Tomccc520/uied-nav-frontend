## ❌ 不做的功能

### 1. 不做文章/博客系统
**原因**：
- 偏离导航网站核心
- 增加系统复杂度
- 用户不需要

### 2. 不做用户系统（开源版）
**原因**：
- 导航网站不需要登录
- 增加使用门槛
- 付费版可以有（云同步需要）

### 3. 不做评论系统
**原因**：
- 维护成本高
- 容易有垃圾评论
- 不是核心功能

### 4. 不做复杂的权限系统
**原因**：
- 开源版单管理员足够
- 企业版可以有多用户
- 保持简单

### 5. 不做 WordPress 版本
**原因**：
- 精力分散
- 技术栈不同
- 市场需求不明确
