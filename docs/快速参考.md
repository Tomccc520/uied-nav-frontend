# UIED 设计导航 - 快速参考

## 🚀 启动命令

```bash
# 后端
cd backend && npm run dev

# 管理后台
cd admin && npm run dev

# 前端
cd frontend && npm start
```

## 🔗 访问地址

| 服务 | 地址 | 说明 |
|------|------|------|
| 前端 | http://localhost:3000 | 用户网站 |
| 管理后台 | http://localhost:5173 | 内容管理 |
| 后端API | http://localhost:3001/api | API服务 |
| 数据库 | http://localhost:5555 | Prisma Studio |

## 📝 常用命令

### 后端
```bash
npm run dev              # 启动开发服务器
npm run prisma:studio    # 打开数据库管理
npm run seed:all         # 重新填充数据
npm run seed:admin       # 创建管理员
```

### 数据库
```bash
npm run prisma:migrate   # 更新数据库结构
npm run prisma:generate  # 生成 Prisma Client
```

## 🛠️ 故障排查

### 后端无法启动
```bash
cd backend
rm prisma/dev.db
npm run prisma:migrate
npm run seed:all
```

### 忘记密码
```bash
cd backend
npm run seed:admin
# 使用默认密码 admin123 登录
```

### 前端无法连接后端
检查 `frontend/.env` 和 `admin/.env` 中的 API 地址
