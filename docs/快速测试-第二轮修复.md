### ✅ 测试2：备案信息动态更新（3分钟）

**验证点：**
- [ ] 保存成功提示

- [ ] 页脚显示更新后的版权信息
- [ ] 备案号显示正确

**预期结果：**
✅ 备案信息从后台动态获取并显示

## 🔍 详细测试场景

### 场景1：修改备案信息并验证

```bash
# 1. 修改备案信息
在管理后台修改：
- 备案号：粤ICP备2022056875号
- 备案链接：https://beian.miit.gov.cn
- 版权信息：© 2025 UIED设计导航 · 佛山市南海区迅捷腾达电子商务服务中心

# 2. 保存后查看API
curl http://localhost:3001/api/site-info | jq '.icp, .icpLink, .copyright'

# 3. 前端验证
打开 http://localhost:3000
滚动到底部查看版权信息
```

### 场景2：添加社交媒体

```bash
# 1. 进入页脚设置 > 关注交流
# 2. 点击"添加社交媒体"
# 3. 填写信息：
名称：微博
类型：微博
上传二维码图片
描述：关注我们的微博
排序：3
显示：开启

# 4. 保存后查看API
curl http://localhost:3001/api/social-media

# 5. 前端验证
打开 http://localhost:3000
滚动到底部查看"关注交流"区域
```

### 场景3：上传Logo

```bash
# 1. 进入站点设置 > 基本设置
# 2. 在"资源设置"区域点击"选择文件"
# 3. 选择一张 Logo 图片
# 4. 等待上传完成
# 5. 查看预览
# 6. 点击"保存设置"

# 7. 前端验证
打开 http://localhost:3000
查看顶部导航栏的 Logo
```
