## 📋 更新内容

### 1. SEO 信息自动抓取功能 ✨

#### 功能描述
在添加网站时，可以通过 SEO 按钮自动从目标网站抓取标题、描述和关键词，无需手动输入。

#### 实现细节

**后端服务** (`backend/src/services/seoScraperService.js`):
- 使用 `axios` 获取网页 HTML
- 使用 `cheerio` 解析 HTML 内容
- 按优先级提取 SEO 信息：
  - **标题**: `og:title` > `twitter:title` > `<title>` 标签
  - **描述**: `og:description` > `twitter:description` > `description` meta
  - **关键词**: `keywords` meta 或从标题/描述中智能提取
- 自动清理和格式化内容
- 限制长度（标题60字符，描述200字符）

**API 路由** (`backend/src/routes/seoScraperRoutes.js`):
- `POST /api/seo-scraper/fetch`
- 参数: `{ url: string }`
- 返回: `{ title, description, keywords }`

**前端集成** (`admin/src/pages/Websites.tsx`):
- URL 输入框右侧新增 "SEO" 按钮
- 点击后自动填充标题、描述和标签字段
- 只填充空字段，不覆盖已有内容
- 显示加载状态和成功/失败提示

#### 使用方法
1. 在添加网站表单中输入网站 URL
2. 点击 URL 输入框右侧的 "SEO" 按钮
3. 等待抓取完成（通常 1-3 秒）
4. 系统自动填充标题、描述和标签
5. 可手动调整自动填充的内容

### 2. 图标 URL 输入支持 🖼️

#### 功能描述
除了上传图标和自动获取 favicon，现在还支持直接输入图标的 URL 地址。

#### 实现细节

**前端更新** (`admin/src/pages/Websites.tsx`):
- 新增 `iconUrlInput` 状态管理
- 在图标区域添加 URL 输入框
- 支持回车键或点击"确定"按钮设置图标
- 编辑时自动回显图标 URL
- 实时预览图标效果

#### 使用方法
1. 在网站图标区域找到 "或输入图标URL" 输入框
2. 输入图标的完整 URL（如：`https://example.com/icon.png`）
3. 按回车键或点击"确定"按钮
4. 图标立即显示在预览区域

#### 支持的图标来源
- 上传本地图片
- 自动获取网站 favicon
- **新增**: 输入任意图标 URL（CDN、图床等）

## 🐛 问题修复

### SSL 证书验证问题
**问题**: 在开发环境中，SEO 抓取某些 HTTPS 网站时出现 "unable to get local issuer certificate" 错误。

**原因**: Node.js 的 axios 默认启用严格的 SSL 证书验证，某些网站的证书链在本地环境无法验证。

**解决方案**:
```javascript
// 在开发环境中禁用 SSL 验证
const httpsAgent = process.env.NODE_ENV === 'production' 
  ? undefined 
  : new https.Agent({ rejectUnauthorized: false });

const response = await axios.get(targetUrl, {
  httpsAgent,
  // ... 其他配置
});
```

**测试结果**:
- ✅ Dribbble.com - 成功抓取
- ✅ Figma.com - 成功抓取
- ✅ 其他 HTTPS 网站 - 正常工作
