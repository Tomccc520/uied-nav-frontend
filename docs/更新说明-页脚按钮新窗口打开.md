# 页脚按钮新窗口打开 - 更新说明

**更新时间**: 2026-01-18  
**更新内容**: 页脚"提交网站"和"更新记录"按钮改为新窗口打开

## 📝 更新内容

### 修改的按钮

1. **提交网站** 按钮
   - 原来：点击后在当前页面跳转到 `/submit`
   - 现在：点击后在新窗口打开 `/submit`

2. **更新记录** 按钮
   - 原来：点击后在当前页面跳转到 `/changelog`
   - 现在：点击后在新窗口打开 `/changelog`

### 技术实现

将 React Router 的 `<Link>` 组件改为原生 `<a>` 标签，并添加 `target="_blank"` 和 `rel="noopener noreferrer"`：

```tsx
// 修改前
<Link to="/submit" className="footer-action-btn">
  提交网站
</Link>

// 修改后
<a 
  href="/submit"
  target="_blank"
  rel="noopener noreferrer"
  className="footer-action-btn"
>
  提交网站
</a>
```

## 🎯 用户体验改进

### 优点

1. **不打断浏览**：用户可以在新窗口提交网站或查看更新记录，不影响当前浏览的页面
2. **方便对比**：可以同时打开多个窗口，方便对比信息
3. **符合习惯**：外部链接通常在新窗口打开，这是用户的常见预期

### 使用场景

- 用户正在浏览某个分类的网站，想提交一个新网站，但不想离开当前页面
- 用户想查看更新记录，但不想关闭当前正在浏览的内容
- 用户想同时打开多个页面进行对比

## 📦 部署说明

### 需要更新的文件

只需要更新前端文件：

```
本地：frontend/build/
服务器：/www/wwwroot/hao.uied.cn/frontend/build/
```

### 部署步骤

#### 使用宝塔面板

1. 打开宝塔文件管理器
2. 进入 `/www/wwwroot/hao.uied.cn/frontend/`
3. 删除旧的 `build` 文件夹
4. 上传本地的 `frontend/build/` 文件夹
5. 刷新网站，按 Ctrl+Shift+R 强制刷新浏览器缓存

#### 使用 FTP/SFTP

1. 使用 FileZilla 或其他 FTP 工具连接服务器
2. 删除服务器上的 `/www/wwwroot/hao.uied.cn/frontend/build/`
3. 上传本地的 `frontend/build/` 文件夹
4. 刷新网站

### 无需重启

- ✅ 前端是静态文件，上传后立即生效
- ✅ 无需重启后端服务
- ✅ 无需重启 Nginx

## 📱 移动端说明

移动端也同样生效：

- 在移动浏览器中，点击按钮会在新标签页打开
- 部分移动浏览器可能会在当前标签页打开（浏览器行为）
- 用户可以通过浏览器的"返回"按钮回到原页面

## 🔒 安全性

添加了 `rel="noopener noreferrer"` 属性，确保：

- **noopener**：防止新窗口通过 `window.opener` 访问原窗口
- **noreferrer**：不发送 referrer 信息，保护隐私

这是打开新窗口的最佳实践。

唯一的变化是点击行为：从当前页面跳转改为新窗口打开。
