# 宝塔部署数据说明

## 📁 数据库文件位置

数据库文件位于：
```
backend/prisma/dev.db
```

这是一个 SQLite 数据库文件，包含所有导入的数据：
- 7 个页面配置
- 460 个分类
- 2461 个网站

## 🚀 部署步骤

### 1. 上传代码
将整个项目上传到宝塔服务器

### 2. 上传数据库文件
确保 `backend/prisma/dev.db` 文件已上传

### 3. 安装依赖
```bash
cd backend
npm install

cd ../admin
npm install

cd ../frontend
npm install
```

### 4. 构建前端
```bash
cd admin
npm run build

cd ../frontend
npm run build
```

### 5. 启动后端
```bash
cd backend
npm start
```

## ⚠️ 注意事项

1. **数据库文件权限**
   确保 `dev.db` 文件有读写权限：
   ```bash
   chmod 664 backend/prisma/dev.db
   ```

2. **环境变量**
   确保 `backend/.env` 文件配置正确：
   ```
   DATABASE_URL="file:./dev.db"
   JWT_SECRET="your-secret-key"
   ```

3. **数据备份**
   定期备份 `dev.db` 文件：
   ```bash
   cp backend/prisma/dev.db backend/prisma/dev.db.backup
   ```
