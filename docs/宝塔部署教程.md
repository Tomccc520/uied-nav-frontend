## 🎓 技术栈说明（新手必读）

这个项目使用了现代 Web 开发的主流技术，下面简单介绍每个技术是什么、有什么用。

### 整体架构图

```
┌─────────────────────────────────────────────────────────────┐
│                        用户浏览器                            │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                     Nginx (Web 服务器)                       │
│  - 处理 HTTPS 请求                                           │
│  - 静态文件服务                                              │
│  - 反向代理 API 请求                                         │
└─────────────────────────────────────────────────────────────┘
          │                    │                    │
          ▼                    ▼                    ▼
┌─────────────┐      ┌─────────────┐      ┌─────────────────┐
│   前端网站   │      │  管理后台   │      │    后端 API     │
│  (frontend) │      │   (admin)   │      │   (backend)     │
│             │      │             │      │                 │
│ React + TS  │      │ React + TS  │      │ Node.js+Express │
│   + Vite    │      │ + Ant Design│      │   + Prisma      │
└─────────────┘      └─────────────┘      └────────┬────────┘
                                                   │
                                                   ▼
                                          ┌───────────────┐
                                          │    SQLite     │
                                          │   (dev.db)    │
                                          └───────────────┘
```

### 前端技术（frontend 和 admin）

| 技术 | 是什么 | 在项目中的作用 |
|------|--------|----------------|
| **React** | JavaScript 前端框架 | 构建用户界面，让网页可以动态更新而不用刷新整个页面 |
| **TypeScript** | JavaScript 的超集 | 给 JavaScript 加上类型检查，减少 bug，代码更可靠 |
| **Vite** | 前端构建工具 | 把代码打包成浏览器能运行的文件，开发时热更新很快 |
| **Ant Design** | UI 组件库（仅 admin） | 提供现成的按钮、表格、表单等组件，管理后台用它快速搭建界面 |

**简单理解**：React 负责页面逻辑，TypeScript 让代码更安全，Vite 负责打包，Ant Design 提供漂亮的组件。

### 后端技术（backend）

| 技术 | 是什么 | 在项目中的作用 |
|------|--------|----------------|
| **Node.js** | JavaScript 运行环境 | 让 JavaScript 可以在服务器上运行，不只是浏览器 |
| **Express.js** | Node.js Web 框架 | 处理 HTTP 请求，定义 API 接口，是后端的骨架 |
| **Prisma** | 数据库 ORM 工具 | 用 JavaScript 代码操作数据库，不用写 SQL 语句 |
| **SQLite** | 轻量级数据库 | 存储所有数据（网站、分类、用户等），数据存在一个文件里 |

**简单理解**：Node.js 是运行环境，Express 处理请求，Prisma 操作数据库，SQLite 存储数据。

### 部署相关技术

| 技术 | 是什么 | 在项目中的作用 |
|------|--------|----------------|
| **Nginx** | Web 服务器 | 处理用户请求，提供静态文件，把 API 请求转发给后端 |
| **PM2** | Node.js 进程管理器 | 让后端服务在后台持续运行，崩溃自动重启 |

### 前后端如何通信

```
前端/管理后台                    后端
    │                            │
    │  1. 发送 HTTP 请求          │
    │  GET /api/categories       │
    │ ─────────────────────────► │
    │                            │  2. 查询数据库
    │                            │  3. 返回 JSON 数据
    │  {"data": [...]}           │
    │ ◄───────────────────────── │
    │                            │
    │  4. 前端渲染数据到页面       │
```

**API 是什么？** API（Application Programming Interface）就是前端和后端约定好的"接口"。比如：
- `GET /api/categories` - 获取所有分类
- `POST /api/websites` - 添加新网站
- `DELETE /api/websites/123` - 删除 ID 为 123 的网站

## 📚 基础知识（先看这里）

### 这个项目有三个部分

| 部分 | 说明 | 部署方式 |
|------|------|----------|
| **frontend** | 用户看到的网站 | 本地构建 → 上传 dist 文件夹 |
| **admin** | 管理后台 | 本地构建 → 上传 dist 文件夹 |
| **backend** | 后端 API 服务 | 上传代码 → 服务器安装依赖 → 运行 |

### 关于数据库

⭐ **重要**：这个项目使用 **SQLite 数据库**，和 MySQL 不一样！

| 对比 | MySQL | SQLite（本项目） |
|------|-------|------------------|
| 安装 | 需要在宝塔安装 MySQL | ❌ 不需要安装任何东西 |
| 配置 | 需要创建数据库、用户、密码 | ❌ 不需要配置 |
| 数据存储 | 存在 MySQL 服务器里 | 存在一个文件里：`dev.db` |
| 部署方式 | 导入 SQL 文件 | 直接上传 `dev.db` 文件 |

**简单说**：`dev.db` 就是你的数据库，把它当成一个普通文件上传就行，不需要在宝塔的「数据库」菜单里做任何操作。

打开宝塔面板 → 软件商店，安装以下软件：

4. PHP 版本选择「纯静态」
5. 点击「提交」

## 🔨 第一步：本地构建前端和管理后台

在你的电脑上操作：

### 1.1 构建前端

```bash
# 进入前端目录
cd frontend

# 创建生产环境配置文件
# 在 frontend 目录下创建 .env.production 文件，内容如下：
REACT_APP_API_URL=https://hao.uied.cn/api

# 安装依赖（如果还没安装）
npm install

# 构建（会生成 build 文件夹）
npm run build
```

构建完成后，`frontend/build/` 文件夹就是要上传的内容。

> ⚠️ **注意**：前端使用 Create React App，构建输出目录是 `build`，不是 `dist`

### 1.2 构建管理后台

```bash
# 进入管理后台目录
cd admin

# 创建生产环境配置文件
# 在 admin 目录下创建 .env.production 文件，内容如下：
VITE_API_URL=https://hao.uied.cn/api

# 构建（会生成 dist 文件夹）
npm run build
```

构建完成后，`admin/dist/` 文件夹就是要上传的内容。

## ⚙️ 第三步：配置后端

### 3.1 修改环境变量

1. 在宝塔「文件」中，进入 `/www/wwwroot/hao.uied.cn/backend/`
2. 编辑 `.env` 文件，修改为以下内容：

```bash
# 数据库配置（指向 SQLite 文件）
DATABASE_URL="file:./prisma/dev.db"

# 服务配置
PORT=3001
NODE_ENV=production

# 安全配置 - 必须修改下面两个值！
JWT_SECRET="这里填64位随机字符串"
PASSWORD_SALT="这里填32位随机字符串"

# CORS 配置
CORS_ORIGINS="https://hao.uied.cn"

# 前端地址（SEO 功能需要，用于生成 sitemap）
FRONTEND_URL="https://hao.uied.cn"
```

### 3.2 生成安全密钥

在宝塔「终端」中执行以下命令生成随机字符串：

```bash
# 生成 JWT_SECRET（复制输出的内容）
openssl rand -hex 64

# 生成 PASSWORD_SALT（复制输出的内容）
openssl rand -hex 32
```

把生成的字符串填到 `.env` 文件对应的位置。

### 3.3 安装后端依赖（必须！）

在宝塔「终端」中执行：

```bash
# 进入后端目录
cd /www/wwwroot/hao.uied.cn/backend

# 安装依赖（这一步必须执行！）
npm install --production

# 生成 Prisma 客户端（这一步也必须执行！）
npx prisma generate
```

⏱️ `npm install` 可能需要几分钟，请耐心等待。

### 3.4 设置文件权限

在宝塔「终端」中执行：

```bash
# 设置数据库文件权限
chmod 664 /www/wwwroot/hao.uied.cn/backend/prisma/dev.db
chown www:www /www/wwwroot/hao.uied.cn/backend/prisma/dev.db

# 设置上传目录权限
mkdir -p /www/wwwroot/hao.uied.cn/backend/uploads
chmod -R 755 /www/wwwroot/hao.uied.cn/backend/uploads
chown -R www:www /www/wwwroot/hao.uied.cn/backend/uploads

# 设置导出目录权限（数据导出功能需要）
mkdir -p /www/wwwroot/hao.uied.cn/backend/exports
chmod -R 755 /www/wwwroot/hao.uied.cn/backend/exports
chown -R www:www /www/wwwroot/hao.uied.cn/backend/exports

# 设置 public 目录权限（SEO 文件需要）
mkdir -p /www/wwwroot/hao.uied.cn/backend/public
chmod -R 755 /www/wwwroot/hao.uied.cn/backend/public
chown -R www:www /www/wwwroot/hao.uied.cn/backend/public
```

### 3.5 启动后端服务

在宝塔「终端」中执行：

```bash
cd /www/wwwroot/hao.uied.cn/backend

# 使用 PM2 启动后端
pm2 start src/index.js --name "hao-uied-api"

# 保存 PM2 配置（服务器重启后自动启动）
pm2 save
pm2 startup
```

### 3.6 验证后端是否启动成功

```bash
curl http://localhost:3001/api/health
```

如果看到以下输出，说明后端启动成功：
```json
{"status":"ok","message":"UIED API is running"}
```

### 3.7 首次部署：重置管理员密码（重要！）

⚠️ **如果你上传的 `dev.db` 是从本地复制的，密码可能无法登录。需要重置密码：**

```bash
cd /www/wwwroot/hao.uied.cn/backend

# 重置管理员密码
node src/utils/resetAdminPassword.js
```

执行后会显示：`✅ 管理员密码已重置为: admin123`

**登录信息**：
- 用户名：`admin`
- 密码：`admin123`

💡 **说明**：
- 只有首次部署或更换 `dev.db` 文件时才需要重置密码
- 以后更新代码时，只要不覆盖 `.env` 和 `dev.db`，就不需要重置密码
- 登录后请立即在管理后台修改密码

## 🌐 第四步：配置 Nginx

### 4.1 修改 Nginx 配置

1. 在宝塔「网站」中，点击 `hao.uied.cn`
2. 点击「设置」→「配置文件」
3. 在 `server` 块内，找到合适位置添加以下 location 配置（注意顺序很重要）：

```nginx
    # API 代理（把 /api 请求转发给后端）
    location /api {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        client_max_body_size 10m;
    }
    
    # 上传文件访问
    location /uploads {
        alias /www/wwwroot/hao.uied.cn/backend/uploads;
        expires 30d;
    }
    
    # SEO 文件访问（sitemap.xml, robots.txt）
    location ~ ^/(sitemap\.xml|robots\.txt)$ {
        root /www/wwwroot/hao.uied.cn/backend/public;
        expires 1d;
    }
    
    # 管理后台静态资源（必须放在 /admin 之前）
    location ^~ /admin/assets {
        alias /www/wwwroot/hao.uied.cn/admin/assets;
        expires 30d;
    }
    
    # 管理后台
    location /admin {
        alias /www/wwwroot/hao.uied.cn/admin;
        index index.html;
        try_files $uri $uri/ /admin/index.html;
    }
    
    # 前端路由（放在最后）
    location / {
        try_files $uri $uri/ /index.html;
    }
```

### 4.2 完整 Nginx 配置示例

如果你想完全替换配置文件，可以使用以下完整配置：

```nginx
server
{
    listen 80;
    listen 443 ssl http2;
    server_name hao.uied.cn www.hao.uied.cn;
    index index.html;
    root /www/wwwroot/hao.uied.cn;

    # SSL 配置（宝塔会自动生成，保留原有的 SSL 配置）
    # ssl_certificate    /www/server/panel/vhost/cert/hao.uied.cn/fullchain.pem;
    # ssl_certificate_key    /www/server/panel/vhost/cert/hao.uied.cn/privkey.pem;

    # 禁止访问敏感文件
    location ~ ^/(\.user.ini|\.htaccess|\.git|\.env|\.svn)
    {
        return 404;
    }

    # API 代理
    location /api {
        proxy_pass http://127.0.0.1:3001;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
        client_max_body_size 10m;
    }

    # 上传文件访问
    location /uploads {
        alias /www/wwwroot/hao.uied.cn/backend/uploads;
        expires 30d;
    }

    # SEO 文件
    location ~ ^/(sitemap\.xml|robots\.txt)$ {
        root /www/wwwroot/hao.uied.cn/backend/public;
        expires 1d;
    }

    # 管理后台静态资源
    location ^~ /admin/assets {
        alias /www/wwwroot/hao.uied.cn/admin/assets;
        expires 30d;
    }

    # 管理后台
    location /admin {
        alias /www/wwwroot/hao.uied.cn/admin;
        index index.html;
        try_files $uri $uri/ /admin/index.html;
    }

    # 前端路由
    location / {
        try_files $uri $uri/ /index.html;
    }

    # 静态资源缓存
    location ~* \.(js|css|png|jpg|jpeg|gif|ico|svg|woff|woff2)$ {
        expires 30d;
    }

    access_log  /www/wwwlogs/hao.uied.cn.log;
    error_log  /www/wwwlogs/hao.uied.cn.error.log;
}
```

4. 点击「保存」

## 🐛 常见问题

### 问题1：访问网站显示 502 Bad Gateway

**原因**：后端没有启动

**解决**：
```bash
# 查看后端状态
pm2 status

# 如果没有运行，重新启动
cd /www/wwwroot/hao.uied.cn/backend
pm2 start src/index.js --name "hao-uied-api"
```

### 问题2：后端启动报错

**解决**：查看错误日志
```bash
pm2 logs hao-uied-api
```

### 问题3：管理后台页面空白

**原因**：Nginx 配置问题

**解决**：检查 `/admin` 的 alias 路径是否正确

### 问题4：上传图片失败或无法登录管理后台

**原因1**：目录权限问题（上传失败）

**解决**：
```bash
chmod -R 755 /www/wwwroot/hao.uied.cn/backend/uploads
chown -R www:www /www/wwwroot/hao.uied.cn/backend/uploads
```

**原因2**：密码不匹配（无法登录）

**解决**：重置管理员密码

## 🛠️ 附录：快速部署脚本

### 本地构建脚本

在项目根目录创建 `build-for-deploy.sh`：

```bash
#!/bin/bash

echo "🔨 开始构建前端..."
cd frontend
npm install
npm run build
echo "✅ 前端构建完成"

echo "🔨 开始构建管理后台..."
cd ../admin
npm install
npm run build
echo "✅ 管理后台构建完成"

echo ""
echo "📦 构建完成！需要上传的文件："
echo "  - frontend/build/ → 服务器 /www/wwwroot/你的域名/frontend/"
echo "  - admin/dist/     → 服务器 /www/wwwroot/你的域名/admin/"
echo "  - backend/        → 服务器 /www/wwwroot/你的域名/backend/"
```

### 服务器初始化脚本

在服务器上创建 `/www/wwwroot/hao.uied.cn/init.sh`：

```bash
#!/bin/bash

SITE_DIR="/www/wwwroot/hao.uied.cn"

echo "📦 安装后端依赖..."
cd $SITE_DIR/backend
npm install --production

echo "🔧 生成 Prisma 客户端..."
npx prisma generate

echo "📁 设置目录权限..."
mkdir -p $SITE_DIR/backend/uploads
mkdir -p $SITE_DIR/backend/exports
mkdir -p $SITE_DIR/backend/public

chmod -R 755 $SITE_DIR/backend/uploads
chmod -R 755 $SITE_DIR/backend/exports
chmod -R 755 $SITE_DIR/backend/public
chmod 664 $SITE_DIR/backend/prisma/dev.db

chown -R www:www $SITE_DIR/backend/uploads
chown -R www:www $SITE_DIR/backend/exports
chown -R www:www $SITE_DIR/backend/public
chown www:www $SITE_DIR/backend/prisma/dev.db

echo "🚀 启动后端服务..."
pm2 delete hao-uied-api 2>/dev/null
pm2 start $SITE_DIR/backend/src/index.js --name "hao-uied-api"
pm2 save

echo "✅ 初始化完成！"
echo ""
echo "请检查服务状态: pm2 status"
echo "查看日志: pm2 logs hao-uied-api"
```
