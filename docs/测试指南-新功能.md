# 新功能测试指南

## 🧪 测试环境准备

### 1. 启动后端服务
```bash
cd backend
npm run dev
```
后端应该运行在 `http://localhost:3001`

### 2. 启动管理后台
```bash
cd admin
npm start
```
管理后台应该运行在 `http://localhost:3002`

### 3. 启动前端
```bash
cd frontend
npm start
```
前端应该运行在 `http://localhost:3000`

## 📋 测试清单

### 一、图片上传功能测试

#### 1.1 访问站点设置
- [ ] 打开管理后台 `http://localhost:3002`
- [ ] 登录（默认账号：admin / admin123）
- [ ] 点击左侧菜单"站点设置" > "基本设置"

#### 1.2 测试 Logo 上传
- [ ] 在"资源设置"区域找到 Logo 上传
- [ ] 点击"上传 Logo"按钮
- [ ] 选择一张图片（建议 PNG 或 SVG 格式）
- [ ] 确认图片预览正确显示
- [ ] 点击"保存设置"
- [ ] 查看是否提示"保存成功"

#### 1.3 测试 Favicon 上传
- [ ] 点击"上传 Favicon"按钮
- [ ] 选择一张图标图片（建议 ICO 或 PNG 格式，32x32 或 64x64）
- [ ] 确认图片预览正确显示
- [ ] 点击"保存设置"

#### 1.4 测试清除功能
- [ ] 点击 Logo 旁边的"清除"按钮
- [ ] 确认预览消失
- [ ] 点击"保存设置"

#### 1.5 验证前端显示
- [ ] 打开前端 `http://localhost:3000`
- [ ] 刷新页面（等待30秒或手动刷新）
- [ ] 查看顶部导航栏的 Logo 是否更新
- [ ] 查看浏览器标签页的 Favicon 是否更新

### 二、关注交流管理测试

#### 2.1 访问社交媒体管理
- [ ] 在管理后台点击"站点设置" > "关注交流"
- [ ] 确认看到默认的两个配置（交流群、公众号）

#### 2.2 测试添加新的社交媒体
- [ ] 点击"添加社交媒体"按钮
- [ ] 填写名称：如"微博"
- [ ] 选择类型：微博
- [ ] 点击"上传二维码"，选择一张二维码图片
- [ ] 填写描述：如"关注我们的微博"
- [ ] 设置排序：3
- [ ] 确保"显示"开关打开
- [ ] 点击"确定"
- [ ] 确认列表中出现新添加的项目

#### 2.3 测试编辑功能
- [ ] 点击某个社交媒体的"编辑"按钮
- [ ] 修改名称或描述
- [ ] 点击"确定"
- [ ] 确认修改生效

#### 2.4 测试显示/隐藏
- [ ] 编辑一个社交媒体
- [ ] 关闭"显示"开关
- [ ] 保存后确认该项在列表中显示为"隐藏"标签

#### 2.5 测试删除功能
- [ ] 点击某个社交媒体的"删除"按钮
- [ ] 确认删除提示
- [ ] 点击"确定"
- [ ] 确认该项从列表中消失

#### 2.6 验证前端显示
- [ ] 打开前端 `http://localhost:3000`
- [ ] 滚动到页面底部
- [ ] 查看"关注交流"区域
- [ ] 确认显示的二维码与后台配置一致
- [ ] 确认只显示"可见"状态的社交媒体
- [ ] 确认排序正确

#### 2.7 测试移动端显示
- [ ] 打开浏览器开发者工具（F12）
- [ ] 切换到移动设备模式
- [ ] 刷新页面
- [ ] 滚动到底部
- [ ] 确认二维码在移动端正确显示
- [ ] 点击"查看更多"按钮
- [ ] 确认展开/收起功能正常

### 三、数据刷新测试

#### 3.1 测试自动刷新
- [ ] 打开前端页面
- [ ] 在管理后台修改站点名称
- [ ] 等待30秒
- [ ] 查看前端是否自动更新（无需手动刷新）

#### 3.2 测试手动刷新
- [ ] 在管理后台修改站点信息
- [ ] 在前端手动刷新页面（F5）
- [ ] 确认立即看到更新

### 四、API 接口测试

#### 4.1 测试图片上传 API
```bash
# 上传图片
curl -X POST http://localhost:3001/api/upload/image \
  -F "file=@/path/to/your/image.png"

# 预期返回：
# {
#   "success": true,
#   "url": "/uploads/upload-1234567890-123456789.png",
#   "filename": "upload-1234567890-123456789.png",
#   "originalName": "image.png",
#   "size": 12345
# }
```

#### 4.2 测试社交媒体 API
```bash
# 获取所有社交媒体
curl http://localhost:3001/api/social-media

# 创建社交媒体
curl -X POST http://localhost:3001/api/social-media \
  -H "Content-Type: application/json" \
  -d '{
    "name": "测试",
    "type": "other",
    "qrCodeUrl": "http://example.com/qr.jpg",
    "description": "测试描述",
    "order": 10,
    "visible": true
  }'
```

#### 4.3 测试站点信息 API
```bash
# 获取站点信息
curl http://localhost:3001/api/site-info

# 更新站点信息
curl -X PUT http://localhost:3001/api/site-info \
  -H "Content-Type: application/json" \
  -d '{
    "siteName": "测试站点",
    "siteTitle": "测试标题",
    "description": "测试描述",
    "keywords": "测试,关键词"
  }'
```
