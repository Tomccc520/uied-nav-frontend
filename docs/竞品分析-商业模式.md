1. **产品矩阵策略**（奈斯猫）

   - 满足不同需求

   - 设计驱动
   - 长期主义

3. **免费增值策略**（Mtab）

   - 再通过增值服务盈利
   - 提高用户粘性

4. **生态建设策略**（综合）
   - 产品生态
   - 服务生态
   - 社区生态
