## 📋 更新内容

### 1. SEO信息自动抓取功能 ✨

**功能描述**：
在添加网站时，点击"SEO"按钮可自动从目标网站抓取标题、描述和关键词。

**实现文件**：
- ✅ `backend/src/services/seoScraperService.js` - SEO抓取服务
- ✅ `backend/src/routes/seoScraperRoutes.js` - API路由
- ✅ `backend/src/index.js` - 路由注册
- ✅ `admin/src/pages/Websites.tsx` - 前端集成

**技术特点**：
- 使用 cheerio 解析 HTML
- 按优先级提取 SEO 信息（og:title > twitter:title > title）
- 智能清理和格式化内容
- 自动处理 SSL 证书验证问题
- 10秒超时保护

### 2. 图标URL输入支持 🖼️

**功能描述**：
网站图标设置新增URL输入方式，支持三种图标设置方法。

**三种方式**：
1. 上传本地图片
2. 自动获取 favicon
3. **新增**: 输入图标 URL

**实现文件**：
- ✅ `admin/src/pages/Websites.tsx` - 添加 iconUrlInput 状态和输入框

### 3. 问题修复 🐛

**SSL证书验证问题**：
- **问题**: 抓取 HTTPS 网站时出现 "unable to get local issuer certificate" 错误
- **原因**: Node.js axios 默认启用严格的 SSL 验证
- **解决**: 在开发环境中禁用 SSL 验证，生产环境保持启用

```javascript
const httpsAgent = process.env.NODE_ENV === 'production' 
  ? undefined 
  : new https.Agent({ rejectUnauthorized: false });
```

## 📝 使用说明

### SEO抓取使用方法

1. 登录管理后台
2. 进入"网站管理"页面
3. 点击"添加网站"按钮
4. 输入网站URL（如：https://dribbble.com）
5. 点击URL输入框右侧的"SEO"按钮
6. 等待1-3秒，系统自动填充标题、描述和标签
7. 可手动调整自动填充的内容
8. 点击"确定"保存

### 图标URL使用方法

1. 在添加/编辑网站对话框中
2. 找到"网站图标"区域
3. 在"或输入图标URL"输入框中输入图标地址
4. 按Enter键或点击"确定"按钮
5. 图标立即显示在预览区域

### 错误处理

- **网络错误**: 返回基于域名的默认信息
- **解析失败**: 返回基于域名的默认信息
- **超时**: 10秒后返回默认信息
- **无效URL**: 返回400错误
