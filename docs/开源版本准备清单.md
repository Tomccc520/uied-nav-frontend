## 📝 具体实施方案

### 方案 1：主题配置系统

**数据库表**：
```prisma
model ThemeConfig {
  id              Int      @id @default(autoincrement())
  primaryColor    String   @default("#3b82f6")  // 主题色
  secondaryColor  String   @default("#8b5cf6")  // 辅助色
  fontFamily      String   @default("system-ui") // 字体
  layoutStyle     String   @default("card")      // card | list
  darkMode        Boolean  @default(false)       // 暗色模式
  customCSS       String?  @db.Text             // 自定义 CSS
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}
```

**后台页面**：`admin/src/pages/ThemeSettings.tsx`
```tsx
// 主题色选择器
<ColorPicker value={primaryColor} onChange={setPrimaryColor} />

// 布局样式选择
<Radio.Group value={layoutStyle} onChange={setLayoutStyle}>
  <Radio value="card">卡片布局</Radio>
  <Radio value="list">列表布局</Radio>
</Radio.Group>

// 暗色模式开关
<Switch checked={darkMode} onChange={setDarkMode} />

// 自定义 CSS
<TextArea rows={10} value={customCSS} onChange={setCustomCSS} />
```

### 方案 2：功能开关系统

**数据库表**：
```prisma
model FeatureFlags {
  id                Int      @id @default(autoincrement())
  searchEnabled     Boolean  @default(true)
  submitEnabled     Boolean  @default(true)
  commentEnabled    Boolean  @default(false)
  userRegister      Boolean  @default(false)
  adsEnabled        Boolean  @default(true)
  aiEnabled         Boolean  @default(false)  // AI 功能（付费版）
  createdAt         DateTime @default(now())
  updatedAt         DateTime @updatedAt
}
```

**后台页面**：在 `SystemSettings.tsx` 中添加
```tsx
<Form.Item label="搜索功能">
  <Switch checked={searchEnabled} onChange={setSearchEnabled} />
</Form.Item>

<Form.Item label="用户提交">
  <Switch checked={submitEnabled} onChange={setSubmitEnabled} />
</Form.Item>

<Form.Item label="用户注册">
  <Switch checked={userRegister} onChange={setUserRegister} />
</Form.Item>
```

### 方案 3：安装向导

**流程**：
```
第 1 步：欢迎页面
  ↓
第 2 步：环境检查（PHP/Node 版本、数据库连接）
  ↓
第 3 步：数据库配置
  ↓
第 4 步：管理员账户
  ↓
第 5 步：站点基础信息
  ↓
第 6 步：完成（生成 .env 文件）
```

**技术实现**：
- 前端：`frontend/src/pages/Install/`
- 后端：`backend/src/routes/installRoutes.js`
- 锁文件：`backend/.installed`（防止重复安装）
